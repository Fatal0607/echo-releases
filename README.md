# Echo

第三方音乐播放器, 把 **QQ 音乐** 和 **网易云音乐** 放进同一个 App: 搜索、推荐、排行榜合在一起看, 一首歌在一个平台放不了时自动换到另一个平台. 非官方客户端, 个人自用.

**本仓库只用于发布安装包, 不包含源代码.**

## 功能

### 双平台

- 搜索、发现页、每日推荐、热搜、排行榜把两个平台的内容合在一起, 同一首歌只显示一条, 两个平台都有的排在前面
- 歌曲、歌单、MV 标出来自 QQ 音乐还是网易云
- 一首歌在原平台放不了 (没有版权、需要会员等) 时, 自动换成另一个平台的同一首继续播放; 播放页也可以手动换平台
- QQ 音乐支持 QQ 扫码、微信扫码、手机号验证码登录; 网易云音乐用网易云 App 扫码登录. 两个账号各自独立, 登录后可以用自己的会员听歌
- 不登录也能用: 本地歌单、我喜欢、最近播放、听歌风格都不需要登录

### 发现与搜索

- 每日推荐 (登录网易云后合并两个平台的每日推荐)、随便听听、为你推荐的歌单、猜你喜欢, 都可以换一批
- 新歌首发 (按地区切换)、推荐 MV、排行榜一键播放
- 搜索时给出补全建议, 保留搜索历史; 热搜榜标出平台和热度
- 搜索结果分单曲、专辑、歌单、歌手、MV 五类

### 播放

- 全屏播放页: 左右滑动切换歌曲信息、封面、歌词三页; 背景颜色跟着封面变化
- 顺序 / 单曲循环 / 随机播放, 播放队列可以拖动排序、移除、清空, 支持「下一首播放」
- 歌单、专辑、排行榜等列表里, 正在播放的歌滚出屏幕时右下角出现定位按钮, 点一下跳回那首歌
- 相似歌曲、定时关闭 (按分钟或播完当前这首)
- 音质可选 SQ 无损 / HQ 高品质 / 标准, 没有对应音质时自动降一档
- 边听边缓存, 听过的歌再听不用重新下载; 重新打开 App 恢复上次的播放进度
- 后台播放, 锁屏和通知栏有播放控件, 还能显示当前这句歌词
- 歌曲信息页: 专辑、发行时间、语种、流派、创作人员、简介等; 封面可以看大图、保存到相册

### 歌词

- 逐字高亮, 当前行用主题色加粗, 自动滚动, 点一行跳到那里
- 外文歌显示中文翻译 (可以关闭)
- 当前平台没有歌词时用另一个平台的歌词

### 歌单与收藏

- 「我喜欢」和本地歌单保存在手机上: 新建、改名、拖动排序、删除, 不会改动平台账号里的数据
- 导入歌单: 粘贴 QQ 音乐 / 网易云的分享链接, 或登录后从账号里多选歌单一次导入
- 平台歌单可以收藏到本地, 再次收藏时可以合并新增的歌
- 本地歌单里的歌可以换成另一个平台的版本
- 本地歌单可以备份到文件、从备份恢复, 方便换手机

### 歌手、专辑、MV 与评论

- 歌手页: 热门歌曲、全部专辑、全部 MV、歌手简介; 两个平台都有这位歌手时可以切换查看
- 专辑详情、官方排行榜
- MV 播放: 全屏, 标清 / 高清 / 超清可选
- 查看歌曲评论 (热门 / 最新), 两个平台都支持

### 听歌记录

- 最近播放 (本机保存最近 200 首)
- 听歌风格: 最近 7 天 / 本月 / 累计听歌量和时长、每天和每月的听歌柱状图、听歌时段、最常听的歌手和歌曲、两个平台的占比, 全部基于本机记录

### 个性化

- 深色模式: 跟随系统 / 浅色 / 深色
- 8 种主题色: 青绿、珊瑚、湖蓝、琥珀、紫罗兰、樱粉、天青、网易红
- 3 种播放页样式: 毛玻璃、歌词优先、满幅封面

### 桌面组件

- 安卓桌面组件「正在播放」, 有方形、竖形、横形三种尺寸, 可以直接播放 / 暂停、切歌、随便听听
- 组件颜色取自当前封面, 拖动调整大小后自动换成合适的排版

### 平板

- 平板跟随系统横竖屏旋转, 横屏时导航在左侧边栏, 播放页分成左右两栏

## 安装与更新

- 下载安装包后打开安装. 首次安装需要在系统设置里允许「安装未知应用」.
- 已经安装的 App 会在启动时自动检查更新, 也可以在「设置 → 检查更新」里手动检查, 在 App 内下载安装, 不用再来这里下载.
- 小的改动会在后台自动更新, 下载好后提示重启即可生效.

## 隐私

- 平台账号的登录凭证只保存在手机本地.
- 「我喜欢」、本地歌单、听歌记录都只保存在手机上.
- App 会上报匿名的使用统计和崩溃信息 (打开了哪些页面、播放次数等), 用于改进体验, 不包含账号、手机号、登录凭证.
