# Echo

第三方音乐播放器, 可以同时登录 QQ 音乐和网易云音乐. 非官方客户端, 个人自用.

**本仓库只用于发布安装包, 不包含源代码.**

## 下载

最新版本 **0.5.2** (2026-10-20): [echo-0.5.2-20.apk](https://github.com/Fatal0607/echo-releases/releases/download/v0.5.2/echo-0.5.2-20.apk) (28.1 MB)

更新内容和历史版本见 [Releases](https://github.com/Fatal0607/echo-releases/releases).

## 安装

- 适用于 Android 手机 / 平板. 下载后打开安装, 首次安装需要在系统设置里允许「安装未知应用」.
- 已经安装的 App 会在启动时自动检查更新, 也可以在「设置 → 检查更新」里手动检查, 不用再来这里下载.
